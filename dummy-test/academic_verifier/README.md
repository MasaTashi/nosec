# Academic Verifier

A tool for detecting AI-generated content, hallucinations, and misunderstandings in academic papers.

## Overview

Academic Verifier is an automated system that collects academic papers from various sources and analyzes them to identify potentially problematic content. It uses the TRSHR API to detect:

1. **AI-Generated Content**: Text that was likely generated by an AI system rather than written by a human.
2. **Hallucinations**: False or fabricated information that has no basis in reality.
3. **Misunderstandings**: Incorrect interpretations or misrepresentations of existing research.

The system generates comprehensive reports that highlight suspicious papers and provide detailed analysis of identified issues.

## Features

- **Multi-Source Paper Collection**: Gather papers from arXiv, PubMed, ScienceDirect, and Springer.
- **Advanced Content Analysis**: Utilize the TRSHR API to detect AI-generated content, hallucinations, and misunderstandings.
- **Comprehensive Reporting**: Generate detailed reports in multiple formats (JSON, HTML, PDF).
- **Configurable Analysis**: Adjust thresholds and analysis parameters to suit specific needs.
- **Caching System**: Efficiently cache API responses and paper metadata to reduce redundant operations.

## Installation

### Prerequisites

- Python 3.8 or higher
- pip (Python package manager)

### Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/academic-verifier.git
   cd academic-verifier
   ```

2. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Configure your TRSHR API key:
   - Edit `config/config.yaml` and replace the placeholder API key with your actual key
   - Alternatively, set the environment variable: `export TRSHR_API_KEY=your_api_key`

## Usage

### Basic Usage

Run the main application:

```bash
python src/main.py
```

This will:
1. Collect papers from configured sources
2. Analyze them for AI-generated content, hallucinations, and misunderstandings
3. Generate a report in the configured output directory

### Command Line Options

```bash
python src/main.py --config path/to/config.yaml --output path/to/output --verbose
```

- `--config`: Path to configuration file (default: config/config.yaml)
- `--output`: Output directory for reports (default: data/reports/YYYY-MM-DD_HH-MM-SS)
- `--verbose`: Enable verbose logging
- `--sources`: Specific sources to collect papers from (e.g., arxiv pubmed)

### Running Tests

To run the basic test script:

```bash
python tests/test_basic.py
```

## Configuration

The system is configured through the `config/config.yaml` file. Key configuration options include:

- **API Settings**: Configure API keys and endpoints for TRSHR and paper sources.
- **Paper Sources**: Specify which sources to collect papers from.
- **Analysis Settings**: Configure analysis models, thresholds, and features.
- **Storage Settings**: Configure directories for papers, cache, and reports.
- **Logging Settings**: Configure logging level and output.

## API Integration

### TRSHR API

The system uses the TRSHR API for content analysis. The API provides:

- Detection of AI-generated content
- Identification of hallucinations
- Recognition of misunderstandings
- Citation checking
- Methodology analysis
- Statistical validation
- Reference verification

To use the API, you need a valid API key from TRSHR.
